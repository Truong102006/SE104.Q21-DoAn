# Frontend

Next.js 16 + React 19 + TypeScript scaffold cho web quan ly cua hang vang bac da quy.

Da setup:

- Tailwind CSS v4.
- shadcn/ui voi Radix UI va Lucide icon.
- Framer Motion.
- React Hook Form, Zod, `@hookform/resolvers`.
- TanStack Table.
- Playwright.

Lenh thuong dung:

```bash
npm run dev
npm run lint
npm run type-check
npm run build
npm run test:e2e
```

Thu muc `src/app` hien chi co shell toi thieu de Next.js build duoc. Chua co UI va chua co logic nghiep vu.
